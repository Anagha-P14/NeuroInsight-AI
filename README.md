**NeuroInsight AI** is a GPU-accelerated Alzheimer's Disease Decision Support System designed to help clinicians identify high-risk patients and make faster, data-driven decisions. Patient data is securely stored in Google Cloud Storage, processed in BigQuery, and cleaned using NVIDIA RAPIDS cuDF for high-performance analytics. An XGBoost machine learning model predicts each patient's Alzheimer's risk, while a FastAPI backend powers an HTML dashboard displaying hospital statistics, patient insights, and personalized risk scores. The platform also enables clinicians to access previous patient records, view AI-generated recommendations, and book follow-up appointments, improving clinical efficiency and supporting earlier intervention for Alzheimer's care.
